# 🖐️ Hand Gesture Controlled Goku

A fun and interactive **computer vision project** where **Goku reacts to real-time hand gestures** captured via webcam.

Built using **Python, OpenCV, and MediaPipe**, this project combines AI with creative visual feedback.

---

## 🎮 Gestures & Actions

| Hand Gesture | Goku Action |
|-------------|------------|
| Fist | Idle / Ready |
| Thumbs Up | Thumbs Up |
| Peace | Victory Pose |
| Open Palm | Power Up |
| Two Thumbs Up | Super Saiyan Mode 🔥 |

---

## 🚀 Features
- Real-time hand tracking
- Accurate finger counting
- Gesture recognition (single & two hands)
- Dynamic character reaction
- Smooth and clean UI

---

## 🛠 Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
